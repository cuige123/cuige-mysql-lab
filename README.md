# 崔哥MySQL实验室

一个面向数据库初学者、课程实验和日常练习的轻量学习工具。它把 SQL 查询练习、示例数据浏览、数据表结构设计和 ER 图编辑集中在一个网页中，帮助学习者从认识表结构开始，逐步练习查询、筛选、排序、分组统计与多表连接，并将数据库设计思路转化为可查看、可编辑的图表和 SQL。

应用以静态网页方式运行，不需要登录或连接远程数据库。SQL 练习由内置的离线引擎执行，示例数据和练习进度保存在当前浏览器中；适合教学演示、个人练习和数据库课程实验入门。网页可在支持现代 JavaScript 的桌面和移动浏览器中使用。

## 项目特点

- **循序渐进的 SQL 练习**：内置 51 道练习题，涵盖基础查询、条件筛选、排序与限制、聚合统计、日期与 NULL 判断，以及多表连接；支持查看题目要求、载入参考 SQL 和本地自动判题。
- **可操作的示例数据库**：提供学生、课程和选课等练习数据，包括 30 名学生、16 门课程及 123 条选课记录，便于观察查询结果和练习不同条件。
- **可视化 ER 图设计**：支持新建实体、编辑字段、拖动布局、创建和调整关系，并删除关系；可表达一对一、一对多、多对一、多对多或自定义关系类型。
- **表结构与 SQL 辅助**：可编辑表和字段信息，生成建表 SQL 与数据字典，并执行基础范式检查。
- **项目与图表管理**：支持在本地保存、切换、导入和导出项目，以及将 ER 图导出为 PNG 或 SVG。
- **面向移动设备**：界面支持触屏操作；项目还包含 Android WebView 外壳代码。
- **离线使用**：网页资源可由 Service Worker 缓存；首次加载和缓存更新仍需要网络环境配合。

## 快速开始

### 直接打开

在浏览器中打开项目根目录的 `index.html`。

### 使用本地静态服务器

在项目根目录运行：

```powershell
python -m http.server 4173
```

然后访问 <http://localhost:4173/index.html>。

## 主要文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 网页界面、题库和主要交互逻辑 |
| `offline-engine.js` | 本地 SQL 执行引擎与示例数据 |
| `er-editor.js` | ER 图编辑、关系管理和自动布局 |
| `er-recognizer.js` | ER 图图片导入相关识别逻辑 |
| `self-test.js` | 页面内置功能自检 |
| `manifest.json`、`sw.js` | PWA 元数据与离线缓存配置 |
| `android/` | Android WebView 外壳项目 |

## 使用说明与限制

- 本项目的离线 SQL 引擎是用于教学练习的轻量兼容实现，**不是完整的 MySQL Server**，只支持一部分常见 SQL；复杂语句、未实现的语法或行为可能无法执行，也不会连接真实数据库。
- 练习数据、项目和完成状态保存在使用者自己的浏览器中，不会自动上传或在不同设备间同步。清理浏览器站点数据可能导致本地保存内容丢失；重要项目请及时导出备份。
- 浏览器中的 ER 图片导入只做版面候选处理，不提供 OCR 文字识别；Android 本地 OCR 能力以及 APK 构建需在对应设备和 Android SDK/Gradle 环境中另行验证。
- 网页适合学习、练习和演示，不应用于生产数据库管理或存储敏感数据。
